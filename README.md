## Project summary  
The Flashcard Application in Android Studio, developed using Kotlin for Assignment 2. The applications aids users when they want to study or practice for examination, it Quizzes’ users on various Historical events. The Application was developed to empower users to multitask and study efficiently on-the go, with key features accessible at their fingertips.

## Key features and customisations 

•	User interface (UI) has manageable design 
•	Consists of multiple screens which allow users navigate through the App 
•	Score. Activity consists of a pop-up message to review the Answer 
•	Digital flash card application with questions and answer 

## Design considerations 
- 	UI design has customised background and image view (Gif) with Varity of colours 
-	Gif incorporation provides highlights key elements, creating an appealing background.

- **Screen 1**: welcome screen which consists of a Start button for users to begin their Quizzes’ as well as a Exist button in case users would like to exist immediately after the App is opened

- **Screen 2**:  Question. Activity (UI) consists of a Text view to display the questions, has a True /False Button for users to answer the questions, An Additional Text view to displays correct / incorrect answers and a    navigation button” Next” to continue to the next screen.

-	**Screen 3**: Score. Activity well designed interface, with text readability throughout the app. The score screen has a two Text view, a Review button and an exist button 
-	Review button provides a pop-up configuration which allows users to check the answers after the quiz has been completed 

-	**Design element** such as colours customized background images and fonts provided the application with an aesthetic appeal.
- A guideline to use the Flashcard Applications and the implementation of GitHub and GitHub Actions 
-	Users are presented with a welcome screen which allows them to start the app, users are directed to the second screen where they are quizzed of various historical facts and are given an option to answer True or False,    users are provided with their final score and are given an option to review the correct answers.
